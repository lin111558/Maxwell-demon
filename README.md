Maxwell Demon：信息热力学教学仿真程序
一、项目简介
本项目围绕麦克斯韦妖问题与信息热力学基本思想，构建了一个基于随机动力学的交互式仿真程序。程序通过可视化方式呈现系统状态演化、比特带变化以及信息流的统计行为，将原本抽象的信息处理过程转化为可观察、可操作的动态画面。
在传统热力学中，系统的不可逆过程满足熵增规律。麦克斯韦妖思想实验提出，若能够利用微观信息对粒子进行选择性控制，似乎可以从热涨落中提取有用功。这一问题促使物理学从统计物理走向信息热力学，并形成以信息、熵与能量关系为核心的研究框架。
本程序以可解麦克斯韦妖模型为基础，旨在为教学与科研提供一个直观平台，使用户能够通过操作与观察理解热力学第二定律的统计本质，以及信息在物理过程中的作用。

二、模型说明
本程序采用一个由三态系统与比特带耦合构成的最小模型。系统具有三个内部状态，并与输入比特流逐次发生相互作用，从而形成六个复合状态。
输入比特流中0和1的不对称程度可用信息偏置参数表示
δ=p_0-p_1
系统在各状态之间的跃迁由随机过程决定，其动力学通过Gillespie算法实现。系统与比特的耦合使得信息变化与系统演化紧密关联。
在统计意义上，系统的方向性行为可通过信息流表征
Φ=⟨Δχ⟩
其中 Δχ 表示单次相互作用中的净变化量。该量反映了系统在长期演化中的统计偏向。

三、仿真内容说明
程序主要包括以下几个可视化部分：
	状态轨道：展示三态系统的动态演化过程
	比特带：显示输入与输出比特序列
	信息界面：实时显示参数与统计量，包括
	步数
	信息偏置参数
	负载参数
	单步信息流
	累计信息流
通过单步演化与连续运行，可以分别观察微观随机过程与宏观统计规律。
